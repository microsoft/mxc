# Planned ProcessContainer schema 0.8 configuration

See the shared [0.7-to-0.8 network schema comparison](../../sandbox-policy/0.8.0/networking/schema-updates.md)
for egress, ingress, and proxy endpoint changes. This page covers the
ProcessContainer-specific proxy peer.

## Identity-scoped proxy

`allowedProxyPeer` identifies a packaged app by package family name or an unpackaged AppContainer by profile name.
Packaging the proxy as an AppContainer provides the strongest OS enforcement and is recommended.

```jsonc
{
  "version": "0.8.0-alpha",
  "containment": "processcontainer",
  "runtimeConfig": {
    "networkProxy": "http://127.0.0.1:8080"
  },
  "processContainer": {
    "network": {
      "allowedProxyPeer": "agent-proxy"
    }
  }
}
```

| Field | Value |
|---|---|
| `runtimeConfig.networkProxy` | HTTP/S loopback URL with an explicit port |
| `processContainer.network.allowedProxyPeer` | Packaged app family name or unpackaged AppContainer profile name |

The omitted `network` block uses deny defaults. See
[Process Container Networking Configuration](../networking.md) for Windows
enforcement details.
